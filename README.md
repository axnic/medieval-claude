Claude Code est devenu l'établi de tous les jours. Et comme tout établi
dont on se sert du matin au soir, il finit par sentir un peu la routine.

Ce dépôt rassemble des skills et plugins qui font remonter Claude Code de
quelques siècles — d'un millénaire, pour être honnête. Une voix d'un autre
âge, une image, un tour de magie dans le clavardage : juste assez pour que
la journée de travail ait un peu plus de panache.

## Le serment

Tout enchantement de ce dépôt jure la même chose :

> **Il habille la forme. Il ne touche jamais au fond.**

| Ce qui peut changer              | Ce qui ne bouge pas                      |
| -------------------------------- | ---------------------------------------- |
| le ton et la voix dans le chat   | le code produit, sa logique              |
| les images, les tournures        | les conventions du projet                |
| l'ambiance                       | les commentaires, les messages de commit |

Si un enchantement fait dériver une seule ligne de code, c'est un bug,
pas une fantaisie.

## Ouvrir le grimoire

Ce dépôt est lui-même un marketplace de plugins Claude Code. Pour y avoir
accès :

```
/plugin marketplace add axnic/medieval-claude
```

Chaque enchantement ci-dessous s'installe ensuite séparément.

## Et ensuite ?

La salle d'armes est encore presque vide, et c'est voulu. D'autres
enchantements viendront s'y accrocher, un par un, tant qu'ils respectent
le serment.
